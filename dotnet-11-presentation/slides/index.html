SLIDE 6: C# 15 UNIONS - OVERVIEW

=====================================================================

SPEAKER NOTES: - Introduce unions conceptually: they are closed sum types (discriminated unions). - It's not just for return types—it's great for domain state machines, event types, and workflow steps. - Because the set of types is closed, the compiler enforces exhaustiveness on pattern matching.

SLIDE 10: ARCHITECTURE NOTE: PRIMARY CONSTRUCTORS

=====================================================================

SPEAKER NOTES: - It's tempting to use primary constructors everywhere because they save a few lines of code. - But in DI services, captured parameters remain mutable in class scope and cannot be marked readonly. - For services, stick to explicit private readonly fields. For DTOs and records, primary constructors are great.

=====================================================================

SLIDE 11: LINQ AGGREGATIONS

=====================================================================

SPEAKER NOTES: - Explain why CountBy is great: previously you had to do `.GroupBy(x => x.Customer).ToDictionary(g => g.Key, g => g.Count())`, which allocated intermediate group objects. - AggregateBy does running accumulation per key. Clarify that `seed: 0m` is simply the starting decimal amount (0.00). - Index() is a nice helper when you need the index of an element alongside the element itself. - [SWITCH TO DEMO]: Run: `dotnet run dotnet-11-presentation/demos/csharp-scripts/05_Linq_Aggregations.cs -p:LangVersion=preview`

SLIDE 12: LINQ OUTER JOINS

=====================================================================

SPEAKER NOTES: - Pre-.NET 10, left joins required `GroupJoin` + `SelectMany` + `DefaultIfEmpty()`. - Now `LeftJoin` is a first-class method on IEnumerable<T>. - Address the review question: Can it join on multiple properties? Yes! You match on an anonymous object or tuple `new { order.TenantId, order.Sku }`. - [SWITCH TO DEMO]: Run: `dotnet run dotnet-11-presentation/demos/csharp-scripts/06_Linq_LeftJoin.cs -p:LangVersion=preview`

SLIDE 13: HYBRIDCACHE

=====================================================================

SPEAKER NOTES: - Explain the real problem: cache stampede / thundering herd. With IMemoryCache, when a key expires under load, 50 requests all hit SQL/Oracle DB at the same time. - HybridCache provides atomic locking so only one query runs. - Emphasize that `tags` are completely optional—you only use them if you want tag-based invalidation.

SPEAKER NOTES: - Clarify what JSON source generation actually is: Roslyn generates the serializer code at compile time. - Reflection is fine for small scripts, but in production APIs source generation guarantees that serialization logic is verified at compile time.

SLIDE 18: RUNTIME ASYNC

=====================================================================

SPEAKER NOTES: - Since C# 5 (2012), async was a compiler transformation. The compiler created a state machine class with MoveNext(). - In .NET 11, CoreCLR natively suspends and resumes managed frames. - This means fewer allocations on high-frequency Dapper calls, and clean stack traces in Datadog or Application Insights without cryptic `<Method>d__1.MoveNext()` lines.
